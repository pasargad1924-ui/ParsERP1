# ParsERP - نرم‌افزار مدیریت یکپارچه تولید، بازرگانی و پروژه‌ها

نسخه اولیه اسکلت برنامه برای شرکت‌های تولیدی تجهیزات الکترونیکی، برق و خدمات تاسیساتی + بازرسی ایمنی.

## ویژگی‌های نسخه فعلی (در حال ساخت)

- رابط کاملاً فارسی و راست‌چین (RTL)
- طراحی مدرن، سبک و کاربرپسند با رنگ‌های شاداب و آرام
- سیستم کاربران و سطح دسترسی نقش‌محور
- آماده‌سازی ماژول‌های: تولید، سریال، انبار، گارانتی، برون‌سپاری، حسابداری پایه
- دیتابیس SQLite رمزنگاری‌پذیر + بکاپ و بازیابی
- معماری تمیز و قابل گسترش به نسخه آنلاین و موبایل

## رنگ‌بندی انتخاب‌شده (Fresh Theme)

- رنگ اصلی: فیروزه‌ای زنده (`#0D9488`) – حس تازگی و اعتماد
- رنگ ثانویه: نارنجی ملایم (`#F97316`) – انرژی بدون خستگی چشم
- پس‌زمینه: خاکستری بسیار روشن (`#F8FAFC`)
- متن: سرمه‌ای تیره (`#0F172A`)
- کارت‌ها و سطوح: سفید با سایه ملایم
- تأکید موفقیت: سبز زمردی، هشدار: کهربایی

این ترکیب هم سرزنده است و هم برای کار طولانی‌مدت چشم را خسته نمی‌کند.

## ساختار پروژه

```
ParsERP/
├── Database/
│   └── Schema.sql              ← اسکیمای کامل دیتابیس
├── ParsERP.Core/               ← لایه منطق و مدل‌ها
│   ├── Models/
│   ├── Data/
│   └── Services/
├── ParsERP/                    ← پروژه WPF (رابط کاربری)
│   ├── Views/
│   ├── ViewModels/
│   ├── Styles/
│   └── Assets/
└── README.md
```

## پیش‌نیاز اجرا روی ویندوز

1. Visual Studio 2022 (یا جدیدتر) با workloadهای:
   - .NET desktop development
   - .NET 8 SDK
2. بسته پیشنهادی UI: MaterialDesignThemes + MaterialDesignColors (برای ظاهر مدرن)

## مراحل بعدی که انجام می‌شود

1. ایجاد پروژه WPF واقعی + استایل RTL و تم رنگی
2. صفحه ورود و مدیریت کاربران
3. داشبورد اصلی با منوی راست‌چین
4. ماژول کالا و تولید سریال
