# دیاگرام جریان داده (Data Flow Diagram) — پارس‌ئی‌آرپی

## دیاگرام جریان داده چیست؟

**دیاگرام جریان داده (DFD)** تصویری است که نشان می‌دهد:

- **داده از کجا می‌آید** (مثلاً کاربر، تأمین‌کننده، فایل اکسل)
- **در کجا پردازش می‌شود** (مثلاً ثبت خرید، تولید سریال، حواله انبار)
- **کجا ذخیره می‌شود** (جداول دیتابیس)
- **خروجی چیست** (گزارش، فاکتور، موجودی، گواهی)

با DFD منطق برنامه را قبل از کدنویسی روشن می‌کنیم؛ اینکه «کدام بخش به کدام بخش داده می‌دهد».

نمادهای رایج:

| نماد | معنی |
|------|------|
| مستطیل باز / منبع خارجی | شخص یا سیستم بیرون (کاربر، مشتری، تأمین‌کننده) |
| دایره یا گوشه‌گرد | فرایند (پردازش) |
| دو خط موازی | مخزن داده (جدول / فایل) |
| فلش | جریان داده |

سطوح:

- **سطح ۰ (Context):** کل سیستم یک جعبه
- **سطح ۱:** ماژول‌های اصلی
- **سطح ۲:** جزئیات یک ماژول (مثلاً فقط انبار)

---

## سطح ۰ — کل سیستم

```
[تأمین‌کننده] ──سفارش/کالا──► ┌─────────────────────┐
[کاربر داخلی] ──عملیات──────► │   پارس‌ئی‌آرپی (ERP)  │ ──گزارش/فاکتور──► [مدیر / حسابداری]
[مشتری]      ──سفارش فروش──► │                     │ ──گواهی/گارانتی─► [مشتری]
[فایل Excel] ──ورود داده───► └─────────────────────┘
```

## سطح ۲ — تمرکز انبار (شروع پیاده‌سازی)

### فرایندهای انبار

1. **رسید انبار (ورود)**  
   ورودی: کالا / سریال / تعداد / مرجع (خرید یا تولید)  
   خروجی: افزایش موجودی + تراکنش StockIn

2. **حواله انبار (خروج)**  
   ورودی: کالا / سریال / تعداد / مرجع (فروش یا مصرف تولید)  
   خروجی: کاهش موجودی + تراکنش StockOut

3. **انتقال بین انبارها**  
   خروجی از انبار مبدأ + ورود به انبار مقصد

4. **انبارگردانی / تعدیل**  
   اصلاح موجودی با دلیل

5. **گزارش موجودی**  
   خواندن از جدول Stock + سریال‌های InStock

### جریان داده انبار

```
[خرید / تولید] ──سند رسید──► (ثبت رسید) ──► || Stock ||
                              │                || StockTransactions ||
                              └──► || SerialNumbers (Status=InStock) ||

[فروش / تولید] ──سند حواله─► (ثبت حواله) ──► || Stock ||
                              │                || StockTransactions ||
                              └──► || SerialNumbers (Status=Sold/Consumed) ||

[کاربر انبار] ──استعلام──► (گزارش موجودی) ──► [صفحه انبار / Excel]
```

### موجودیت‌های داده مرتبط با انبار

| مخزن | نقش |
|------|-----|
| Products | تعریف کالا و کد سریال |
| Warehouses | لیست انبارها |
| Stock | موجودی فعلی هر کالا در هر انبار |
| StockTransactions | تاریخچه ورود/خروج |
| SerialNumbers | رهگیری تک‌تک اقلام سریالی |
| PurchaseOrders / ProductionOrders / SalesOrders | مرجع تراکنش |

---

## اصل رهگیری یک محصول (از دید داده)

```
خرید (تأمین‌کننده، قیمت، کاربر)
    → رسید انبار مواد
        → مصرف در تولید + ثبت کارکنان/شیفت
            → تولید سریال ۱۰ رقمی + پارت
                → رسید انبار محصول
                    → حواله فروش + مشتری + قیمت + ارسال
                        → گارانتی / تعمیر (در صورت نیاز)
```

هر فلش در سیستم واقعی با `UserId` و زمان در AuditLog یا خود سند ثبت می‌شود.
